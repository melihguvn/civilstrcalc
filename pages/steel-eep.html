Design Background — Extended End Plate Connection (AISC 360-22 / DG4) ▾
Overview — Extended End Plate Configurations

An extended end plate moment connection transfers both shear and moment from a beam to a column. The plate is shop-welded to the beam end (CJP or fillet welds at flanges and web) and field-bolted to the column flange. The plate extends beyond both beam flanges, placing tension bolts in the extended portions.

AISC Design Guide 4 covers three standard configurations:

ConfigBoltsPlateTypical use
4E4 (2 per flange)UnstiffenedLight to moderate moment
4ES4 (2 per flange)StiffenedModerate moment, thinner plate
8ES8 (4 per flange)StiffenedHeavy moment connections, seismic

Design checks include: bolt tension (with prying), end plate flexural yielding (yield line method), column flange flexural yielding, column web local yielding, column web local crippling, column web compression buckling, panel zone shear, and weld design.

Bolt Tension with Prying — DG4 §3

The tension force per bolt row is determined from the applied moment. For an 8ES configuration with 4 bolt rows (2 above top flange, 2 below bottom flange), DG4 uses a simplified model where each bolt row carries a tributary share of the flange force Tf = Mu / deff.

Prying action amplifies the bolt tension. DG4 provides a yield line model for the end plate that gives the no-prying bolt force limit and the plate thickness required to preclude prying. When tp ≥ tp,req (no-prying condition), the bolt design force equals Tf/nbolts per row.

End Plate Flexure — Yield Line Method

The end plate is designed using a yield line model (DG4 §3.2). The virtual work method gives the required plate thickness based on the plastic moment capacity per unit length mp = Fy tp² / 4. Each configuration has a specific yield line pattern that accounts for the bolt positions (pf, g, pb) and plate width bp.

Column-Side Checks — DG4 §4

The column must be checked for the concentrated flange force Tf delivered by the beam top/bottom flanges through the plate. Limit states per AISC 360-22:
