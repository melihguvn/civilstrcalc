Design Procedure Overview

  1. Select section and compute properties (A, Zx, Zy, Sx, rx, ry, J, Cw).
  2. Compute nominal axial capacity φcPn for both axes using AISC §E3. Governing KL/r controls.
  3. Compute strong-axis moment capacity φbMnx considering LTB zones (§F2).
  4. Compute weak-axis moment capacity φbMny (§F6, no LTB).
  5. Evaluate interaction ratio using §H1-1. If Pu/φcPn ≥ 0.2 use H1-1a; otherwise H1-1b.

Interaction Equations — AISC 360 §H1-1

H1-1a — High axial (Pu/φPn ≥ 0.2) Pu / (φcPn) + (8/9)[Mux/(φbMnx) + Muy/(φbMny)] ≤ 1.0
H1-1b — Low axial (Pu/φPn < 0.2) Pu/(2φcPn) + Mux/(φbMnx) + Muy/(φbMny) ≤ 1.0

φc = φb = 0.90. The two equations share the same boundary point at Pu/φPn = 0.2, M/φMn = 0.9, ensuring a continuous interaction surface. Cb = 1.0 assumed (uniform moment, conservative).

Why two equations? When axial force dominates (≥20% capacity), bending reduces the remaining capacity by 8/9 of its ratio — yielding a steeper envelope. When axial is small, the column behaves more like a beam-column with near-full flexural capacity.

Axial Compression Capacity — AISC 360 §E3

The critical buckling stress depends on the governing slenderness ratio KL/r (larger of strong and weak axis):

Elastic critical stressFe = π²E / (KL/r)²
Inelastic   KL/r ≤ 4.71√(E/Fy)  [typically ≤200 for A992]Fcr = 0.658(Fy/Fe) × Fy
Elastic   KL/r > 4.71√(E/Fy)Fcr = 0.877 × Fe   (10% knock-down for imperfections)
Nominal & design strengthPn = Fcr × A    φcPn = 0.90 × Pn
Limit KL/r ≤ 200 is recommended by AISC commentary as a practical upper bound for compression members. Above this, columns are very slender and efficiency drops sharply.

Strong-Axis Flexure & LTB — AISC 360 §F2

Three zones govern depending on the unbraced length Lb (taken as a fraction of column height):

Inelastic LTB (Lp < Lb ≤ Lr) Mnx = Cb[Mp − (Mp − 0.7FySx) × (Lb−Lp)/(Lr−Lp)] ≤ Mp
Elastic LTB (Lb > Lr) Fcr = Cbπ²E / (Lb/rts)² × √(1 + 0.078Jc/(Sxho) × (Lb/rts)²)    Mnx = FcrSx ≤ Mp

Weak-Axis Flexure — AISC 360 §F6

No LTB possible for bending about the weak axis. Capacity is governed by local flange yielding only:

§F6 (compact flanges)Mny = FyZy ≤ 1.6FySy

The 1.6FySy cap prevents overly optimistic plastic moments for sections with very stocky flanges.

Design Procedure Overview

  1. Compute elastic critical axial load Ncr = π²EI/(KL)² for both axes.
  2. Compute non-dimensional slenderness λ̄ = √(Afy/Ncr) for each axis.
  3. Select buckling curve (a/b/c) from Table 6.2 based on cross-section type and h/b ratio.
  4. Calculate reduction factor χ using the Perry–Robertson formula and get Nb,Rd.
  5. Compute Mcr for LTB, derive χLT, get Mb,Rd and MRd,z.
  6. Check both interaction equations 6.61 and 6.62 (§6.3.3 Method 2).

Axial Buckling — EN 1993-1-1 §6.3.1

Elastic critical loadNcr = π²EI / (KL)²
Non-dimensional slendernessλ̄ = √(Afy / Ncr)
Ayrton–Perry (Robertson) factorφ = 0.5[1 + α(λ̄ − 0.2) + λ̄²]
Reduction factor χχ = 1 / [φ + √(φ² − λ̄²)] ≤ 1.0
Buckling resistanceNb,Rd = χ × A × fy / γM1   (γM1 = 1.0)

The imperfection factor α reflects initial out-of-straightness, residual stresses, and end restraint imperfections. Higher α = more conservative curve.

Interaction Equations — EN 1993-1-1 §6.3.3 Method 2 (Annex B)

Eq. 6.61 (strong-axis check) NEd/(χyNRk/γM1) + kyyMy,Ed/(χLTMy,Rk/γM1) + kyzMz,Ed/(Mz,Rk/γM0) ≤ 1.0
Eq. 6.62 (weak-axis check) NEd/(χzNRk/γM1) + kzyMy,Ed/(χLTMy,Rk/γM1) + kzzMz,Ed/(Mz,Rk/γM0) ≤ 1.0

Interaction factors (Cmy=Cmz=1.0 for uniform moment, conservative):

Both equations must be satisfied. Eq. 6.61 tends to govern when strong-axis moment is large; Eq. 6.62 governs when weak-axis buckling or moment is critical. The calculator reports the maximum of the two ratios.

Design Procedure Overview

  1. Compute Ncr = π²EI/(KL)² for both axes. Use E = 200,000 MPa, G = 77,000 MPa.
  2. Compute λ̄ and χ using the same Ayrton–Perry formula as EC3, but with IS 800 Table 7 buckling curves.
  3. Design axial stress fcd = χ × fy / γm0 (govern by minimum axis). Pd = A × fcd.
  4. Compute Mcr, λ̄LT, χLT using IS 800 Table 6b LTB curves. Mdx = χLT × Zpl,x × fy/γm0.
  5. Weak-axis: Mdz = Zpl,z × fy / γm0 (no LTB).
  6. Check linear interaction §9.3.2.2: P/Pd + Mx/Mdx + My/Mdz ≤ 1.0.

Axial Compression — IS 800:2007 §7.1

γm0 = 1.10 (IS 800 Table 5). The design compressive strength is:

Design axial capacityPd = A × fcd    where    fcd = χ × fy / γm0
Governing axisfcd = min(fcd,x, fcd,y)   — both axes checked independently
IS vs EC3 partial factors: IS 800 uses γm0 = 1.10 (EC3 uses 1.00). This makes IS 800 approximately 10% more conservative than EC3 for the same section and yield strength.

Linear interaction check P / Pd + Mx / Mdx + My / Mdz ≤ 1.0
Comparison with EC3: IS 800 uses a single linear interaction equation, while EC3 §6.3.3 uses two equations with amplification factors kyy, kzz, kyz, kzy. The IS 800 approach is simpler but may be more conservative for stocky columns (low λ̄) and less conservative than EC3 for slender columns with high bending.

Overview

TSDS 2016 (Türk Çelik Yapı Tasarım Yönetmeliği) is the Turkish steel design standard. It adopts the AISC 360-10/16 LRFD framework directly, with SI units (MPa, kN, mm). All interaction equations, buckling checks, and resistance factors are identical to AISC — only units and some load combinations differ.

TSDS = AISC 360 in SI: The design procedure is exactly the same as the AISC tab above. Refer to those formulas for full derivations. Key difference: E = 200,000 MPa (vs 29,000 ksi in AISC), Fy in MPa.

Axial Compression — TSDS 2016 §5.3 (= AISC §E3)

Elastic critical stressFe = π²E / (KL/r)²    [MPa]    E = 200,000 MPa
Inelastic: KL/r ≤ 4.71√(E/Fy)Fcr = 0.658(Fy/Fe) × Fy
Elastic: KL/r > 4.71√(E/Fy)Fcr = 0.877 × Fe
Design strengthφcPn = 0.90 × Fcr × A    [kN]

Flexure & LTB — TSDS 2016 §6 (= AISC §F)

Same three-zone LTB model as AISC §F2. Lp and Lr formulas identical; all section properties in mm.

Plastic zone (Lb ≤ Lp)φbMnx = 0.90 × Fy × Zx  [kN·m]  (Zx in mm³, divide by 10&sup6;)
Weak axis (§F6)φbMny = 0.90 × min(FyZy, 1.6FySy)  [kN·m]

H1-1a (Pu/φPn ≥ 0.2) Pu/(φcPn) + (8/9)[Mux/(φbMnx) + Muy/(φbMny)] ≤ 1.0
H1-1b (Pu/φPn < 0.2) Pu/(2φcPn) + Mux/(φbMnx) + Muy/(φbMny) ≤ 1.0

Effective Length Factor K — Column End Conditions

The effective length KL represents the distance between inflection points of the buckled shape. K depends on the rotational and translational restraint at each end.

K Factor Reference Table

End ConditionK (theoretical)K (AISC rec.)Notes
Pin–Pin (both ends free to rotate)1.001.00Standard braced frame column
Fixed–Pin (one end restrained)0.6990.80Accounts for realistic fixity
Fixed–Fixed (both ends restrained)0.5000.65No sway assumed
Fixed–Free (cantilever)2.002.10Free top can translate + rotate
Pin–Fixed (sway permitted)2.002.00Unbraced frame, conservative
Sway vs. no-sway frames: The theoretical K values above assume no sidesway. In an unbraced (sway) frame, K ≥ 1.0 always. The K values 0.5–0.7 are only valid if lateral drift is prevented by bracing, shear walls, or rigid diaphragms.

Strong vs. Weak Axis & Lb

Kx applies to strong-axis (in-plane) buckling; Ky applies to weak-axis (out-of-plane) buckling. The larger of KL/rx and KL/ry governs the axial design. The LTB unbraced length Lb equals the full column height multiplied by the unbraced fraction input (0–1), representing the distance between lateral braces on the compression flange.

Alignment Chart Method (Jackson–Moreland)

For columns in frames, K can be determined from the stiffness ratios Gtop and Gbot using the AISC alignment charts (Commentary §C-C2):

G factor at each endG = Σ(EIcol/Lcol) / Σ(EIbeam/Lbeam)

G = 1.0 for a theoretically fixed base (pinned base: G = 10). The alignment chart then gives K for the braced or unbraced frame case. This calculator uses the K values you input directly — determine them from the alignment chart or engineering judgment for frame columns.
